# Short Answer

When invoked:
- Answer the user's question directly.
- Keep the response to 1–3 sentences where possible.
- Avoid introductions, unnecessary explanations and summaries.
- Use bullets only when they make the answer clearer.
- Include technical details or commands when necessary.
- Preserve accuracy and important warnings.
- Expand only if the question genuinely requires it.
